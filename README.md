# Machine Learning Implementations

This repository serves as a comprehensive collection of Machine Learning implementations, encompassing key domains such as Clustering, Classification, Recommendation Systems, and Regression. 

## Covered Algorithms
*   **Clustering:** K-Means, DBSCAN, Hierarchical Clustering
*   **Classification:** Support Vector Machine (SVM), K-Nearest Neighbors (KNN), Decision Tree, Logistic Regression
*   **Regression:** Simple Linear, Multiple Linear, Polynomial, Non-Linear Regression
*   **Recommendation Systems:** Content-based, Collaborative Filtering
